# Fin Game — документация

Сопроводительная документация игры «Fin Game» — детского финансового тамагочи для Android: ребёнок
заботится о питомце, получает монеты раз в день, планирует бюджет, копит на цели, открывает вклад и
проходит квесты; взрослый за простым замком видит прогресс и добавляет свои задания и награды.

Документация описывает то, что есть в коде. Числа и формулы взяты из исходников; рядом указаны
классы и константы, где они заданы. Пути к исходникам даны относительно
`app/src/main/java/com/legacy/fingame/`, пути к данным — относительно `app/src/main/assets/`, если
не указано иное.

Краткое описание проекта и быстрый запуск — в корневом [README](../README.md).

## С чего начать

- Собрать и запустить — [build.md](build.md).
- Понять устройство кода — [architecture.md](architecture.md), затем файл нужной подсистемы.
- Добавить контент без изменения кода — примеры в [items.md](items.md) (предмет),
  [quests.md](quests.md) (квест), [animals.md](animals.md) (животное).
- Как решения ребёнка превращаются в игровой результат — [pet-growth.md](pet-growth.md) и
  [economy.md](economy.md).
