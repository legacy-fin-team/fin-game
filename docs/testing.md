## 3. Ручные сценарии

Удобнее проверять на debug-сборке: в ней есть «+12 ч», которая пропускает любое ожидание, в том
числе паузы и кулдауны квестов, и «Ещё раз» у пройденного квеста (см. [build.md](build.md)).

| № | Сценарий | Шаги | Ожидаемый результат |
|---|---|---|---|
| M1 | Первый запуск | Установить, открыть | Подсказка «Привет! Выбери питомца»; после «Понятно!» — выбор вида, окраса, имени; затем главный экран, стартовый баланс, шкалы полные, подсказка «Это дом питомца» |
| M2 | Подсказки по экранам | Открыть магазин, инвентарь, квесты, бюджет, журнал; закрыть каждую подсказку; вернуться на эти экраны | Каждая подсказка показывается один раз; после «Помощь» → «Показать подсказки заново» — снова при входе на экран |
| M3 | Бонус дня и бюджет | Нажать «Бонус дня +50» | +50 на балансе, строка «Бонус дня» в журнале, открывается бюджет |
| M4 | Раскладка | Распределить ползунками и «−/+», подтвердить | «Останется» = остаток; после подтверждения план не меняется |
| M5 | Покупка в пределах плана | Добавить еду в корзину, купить | Баланс уменьшился, товар в инвентаре, «Обязательные» потрачены, возврат на главный экран |
| M6 | Перерасход плана | Положить в корзину одежду сверх плана, «Купить» | В окне «Покупка» — «Необязательные: +N сверх плана», покупка возможна |
| M7 | Нехватка денег | Корзина дороже баланса | «Не хватает монет», «Ещё нужно N» |
| M8 | Кормление | Инвентарь → любая еда → «Съесть» | Шкалы меняются на эффекты товара из `items.xml`, количество −1 шт. |
| M9 | Одежда | Купить одежду, «Надеть»; купить другой вариант, надеть | Одежда на питомце; надевается только один вариант; тот же вариант второй раз купить нельзя |
| M10 | Декор | Купить декор, «Поставить» / «Убрать» | Декор в комнате; в инвентаре состояние «Стоит» |
| M11 | Вклад | При планировании положить сумму на вклад; «+12 ч» до дня погашения | В день погашения возвращается сумма и проценты по ставке срока («Проценты по вкладу») |
| M12 | Досрочное закрытие | Открыть вклад, закрыть досрочно | Окно «Проценты сгорят», возвращается только сумма |
| M13 | Цель | Звёздочка на товаре | Цель в карусели с прогрессом; после покупки исчезает |
| M14 | Убывание шкал | Закрыть приложение на 1 ч | Сытость −36, настроение −24, здоровье −12 |
| M15 | Рост | Держать шкалы полными (кормить и играть между нажатиями), «+12 ч» до смены этапа — по два нажатия на день, всего `Growth.STAGE_MILLIS` роста | Питомец на следующем этапе, одежда на нём — тоже; за одни-двое суток этап не меняется |
| M16 | Плохой уход | Не кормить; «+12 ч» четыре раза; бонус дня; магазин | Подсказка под питомцем; бонус уменьшается с каждым днём серии; одежда и декор дороже на `optionalMarkupPercentPerDay` за день серии, еда и игрушки — по прежней цене |
| M17 | Восстановление | После M16 накормить и поиграть до индекса ≥ 0,5 (например, едой и игрушкой), дождаться конца дня питомца | Серия обнуляется, бонус снова полный, цены базовые, подсказка исчезает |
| M18 | Перевод часов назад | Перевести часы устройства на день назад | Бонус дня повторно не выдаётся, шкалы не восстанавливаются |
| M19 | Перезапуск | Выгрузить приложение в середине планирования | Черновик раскладки и весь прогресс сохранены |
| M20 | Квест | «Копилка» → «В копилку»; через 2 минуты (или после «+12 ч») «Копить дальше» | Сначала «Следующий шаг через …», затем +40 монет, «Квест: Копилка» в журнале |
| M21 | Кулдаун квеста | Пройти «Копилку», вернуться к списку | Отсчёт «Доступен через ч:мм:сс» — около 3:00:00 (кулдаун «Копилки» 180 мин); в демо-сборке «+12 ч» снимает кулдаун |
| M22 | Сброс прогресса | Настройки → «Сбросить прогресс» → подтвердить | Выбор питомца, стартовый баланс, подсказки снова показываются; громкость и тема прежние |
| M23 | Замок взрослого | Настройки → «Режим взрослого», неверный и верный ответы | Неверный — встряска и новые примеры; верный — хаб взрослого |
| M24 | Проверка квеста взрослым | Свой квест с «Проверяю я»; ребёнок выбирает; взрослый «Не засчитано», затем «Засчитать» | «Ждём, пока взрослый проверит»; после «Не засчитано» — «Взрослый пока не засчитал этот шаг. Попробуй ещё раз!»; после «Засчитать» — награда |
| M25 | Изменение своего квеста | Изменить квест, который ребёнок проходит | Предупреждение о сбросе прохождения; после сохранения квест начинается заново |
| M26 | Изменение монет взрослым | «Журнал» → «Изменить монеты» → «Добавить» 50 «за уборку»; «Убрать» больше баланса; без причины | +50 и «Взрослый добавил 50: за уборку»; остальное не сохраняется |
| M27 | Награда из жизни | Взрослый добавляет товар «Другое»; ребёнок покупает и «Использовать» | Предмет исчезает; во вкладке «Награды» запись с именем питомца и временем |
| M28 | Прогресс по темам | Составить план, купить еду, открыть вклад; взрослый → «Прогресс» | «Обязательное и желаемое», «Вклад» — «Освоено» или «В процессе»; прочие — «Тема ещё впереди» |
| M29 | Доступность | TalkBack; шрифт 1,3; ширина 360 dp; альбом; планшет | Кнопки озвучиваются, подписи не обрезаются, ничего не накладывается |
| M30 | Анимации | Выбрать рыбку; Настройки → выключить «Анимации»; погладить питомца; открыть и закрыть окно; включить снова | Выключено: рыбка стоит на первом кадре, три сердечка появляются над головой и исчезают на месте, экраны и окна меняются без перехода. Включено — всё снова движется; после перезапуска настройка сохранена |
| M31 | «Пикник» на три дня | Накопить 300 монет; «Пикник» → пройти день 1; «+12 ч» дважды; ответить на пять вопросов и выбрать занятие; «+12 ч» дважды; пройти день 3 | Между днями «Следующий шаг через …»; за верные ответы +10; в конце +150 и прогресс 100 % при лучших выборах |
