# UX/UI, доступность, разрешения и данные

Обоснование решений интерфейса, настройки доступности, разрешения Android, какие данные хранятся и
как удалить профиль.

Пути к исходникам даны относительно `app/src/main/java/com/legacy/fingame/`.

Связанные разделы: [архитектура и хранилище](architecture.md), [образовательный контент](education.md),
[сцена и жесты](scene.md), [тестирование](testing.md).

## 1. Обоснование решений

| Решение | Почему |
|---|---|
| Питомец в центре игры | Забота о живом существе даёт понятную причину тратить разумно: обязательные траты — это еда и игры питомца |
| Пиксельная графика и шрифт Press Start 2P | Узнаваемый игровой стиль, крупные простые формы; сцена масштабируется только целыми шагами, без размытия |
| Реальное время | Приучает к регулярности: доход раз в день, питомец ждёт заботы; для показа есть демо-перемотка «+12 ч» |
| Бюджет открывается сам после бонуса дня | Планирование встроено в цикл: получил деньги — распредели |
| Ввод сумм без клавиатуры | Ползунок и кнопки «−/+» с круглым шагом (1, 5, 10, 25, 50…) — ребёнку не нужно набирать числа |
| Перерасход — предупреждение, а не запрет | Ребёнок сам принимает решение и видит последствия в итоге периода |
| Цель ставится звёздочкой в магазине | Там, где возникает желание; сразу видна на главном экране |
| Подсказки по экранам вместо одного большого окна | Ребёнок узнаёт о разделе, когда впервые в него попадает; одна подсказка за раз, 1–3 коротких абзаца; перечитать можно в «Помощи» |
| Словарик «Помощь» | Термины объяснены детским языком и доступны в любой момент, не мешая игре |
| Штрафы за плохой уход мягкие и объясняются словами | Ребёнок видит причину («голодный», «скучает») и что исправить; питомец не болеет и не умирает, еда и игрушки не дорожают |
| Кулдаун квестов и отсчёт «Доступен через 1:02:03» | Квест нельзя «фармить» ради монет; ребёнок видит, когда он снова откроется |
| Проверка квеста взрослым «Сам / Проверяю я» | Задания о реальных делах засчитываются только после подтверждения родителя |
| Изменение монет взрослым только с причиной | Любое вмешательство видно ребёнку в журнале и объяснено |
| Раздел «Другое» — награды из жизни | Игровые монеты можно обменять на договорённость с родителем; родитель видит, что и когда использовано |
| «Прогресс» без оценок | «Освоено / В процессе / Тема ещё впереди» показывают родителю, о чём поговорить, без отметок ребёнку |
| Замок взрослого — примеры на умножение | Защищает от случайного входа маленького ребёнка без паролей и учётных записей |
| Ошибки данных не роняют игру | Некорректные записи XML и сохранения пропускаются; отсутствующий спрайт заменяется заметной заглушкой |

## 2. Доступность и адаптивность

| Мера | Состояние | Где |
|---|---|---|
| Громкость звуков и музыки | Два ползунка 0–100 в настройках; 0 — выключено (`GameSettings.soundVolume`, `musicVolume`) | `ui/screens/SettingsScreen.kt`, `game/settings/*` |
| Щелчок кнопок | Звучит только при включённых звуках (`ClickSound.enabled`) | `ui/ClickSound.kt`, `ClickSoundTest` |
| Звук не несёт важной информации | Звуки — только щелчки и реакция на поглаживание; всё важное показано текстом | — |
| Анимации | Плавная смена экранов, всплывание окон, плавающая рыбка, сердечки при поглаживании, встряска примеров в замке взрослого при неверном ответе. Всё это выключается переключателем «Анимации» в настройках (`GameSettings.animationsEnabled`, по умолчанию включено): спрайты стоят на первом кадре, сердечки появляются и исчезают на месте, экраны и окна меняются без перехода, замок не трясёт строки. Системную настройку Android «Отключить анимацию» игра не читает | `ui/theme/Motion.kt`, `utils/SpriteLoader.kt`, `game/scene/PetTouch.kt`, `ui/screens/SettingsScreen.kt`; тесты `SpriteFramesTest`, `HeartBurstTest`, `GameSettingsRepositoryTest` |
| Тема | «Светлая / Тёмная / Авто» (по системе) | `ui/theme/Theme.kt`, `ThemeMode` |
| Описания для TalkBack | Кнопки-картинки, шкалы, баланс, цели, питомец (около 80 мест с `contentDescription` / `semantics` в `ui/`) | `ui/screens/*`, `ui/components/*` |
| Размер нажимаемых элементов | Главные кнопки главного экрана 80 и 64 dp, остальные нажимаемые элементы главного экрана — не меньше 40 dp (`MinTouchTarget`), кнопки-«пилюли» не меньше 44 dp, строки журнала 48 dp, кнопки закрытия и «−/+» — 40 dp; на планшете (≥ 600 dp) кнопки ×1,3 | `MainScreen.kt`, `GameComponents.kt` (`PillMinTouchSize`), `LogScreen.kt`, `ui/theme/Dimens.kt` |
| Размер текста | Пиксельный шрифт Press Start 2P. Основной текст игры, включая подписи кнопок, — `bodyMedium` 13 sp (55 обращений в `ui/`); мелкие подписи — `bodySmall` и `labelSmall` 11 sp (38 обращений); заголовки карточек — `titleMedium` 16 sp, заголовки экранов — 20–24 sp. `bodyLarge` (17 sp) в интерфейсе не используется. Пиксельный шрифт при том же кегле визуально крупнее обычного, но **основной текст меньше рекомендованных ТЗ 16 sp** | `ui/theme/Type.kt` |
| Системное увеличение шрифта | Вёрстка рассчитана на масштаб 1,3: подписи переносятся или уменьшаются по месту; 15 файлов с превью `fontScale = 1.3` | `ShopCardSizing.kt`, `PillButtonSizing.kt`, `GoalsCarousel.kt` и др. |
| Узкий (360 dp) и низкий (< 480 dp) экран | Отдельные раскладки | `GameDimens.isShortScreen`, `MainScreenLayoutTest` |
| Альбомная ориентация | Главный экран перестраивается; текст подсказок прокручивается | `MainScreen.kt`, `ScreenHint.kt` |
| Ширина контента на планшете | Не больше 560 dp | `GameDimens.ContentMaxWidth` |
| Edge-to-edge и системные отступы | Есть | `MainActivity.kt` |
| Подтверждение необратимых действий | «Сбросить прогресс», удаление своего квеста, досрочное закрытие вклада («Проценты сгорят»); при изменении квеста, который ребёнок проходит, форма предупреждает о сбросе прохождения | `SettingsScreen.kt`, `AdultQuestsTab.kt`, `BudgetScreen.kt` |
| Цвет — не единственный признак | Категории трат подписаны словами, перерасход — текстом «+N сверх плана», состояние питомца — подсказкой словами | `MoneyFormat.kt`, `PetCareRules.explain` |

Отличия от рекомендаций ТЗ: кнопки закрытия и «−/+» — 40 dp, выбор варианта товара — 36 dp,
звёздочка цели — 30 dp (рекомендовано 48 dp) — это нужно исправить в коде, см. [roadmap.md](roadmap.md).
Основной текст — 13 sp, подписи — 11 sp (рекомендовано 16 sp) — это сознательное решение под
пиксельный шрифт, обоснование — в [tz-compliance.md](tz-compliance.md), пункт 2.2.4.

## 3. Разрешения Android

Манифест (`app/src/main/AndroidManifest.xml`) не запрашивает ни одного разрешения. В собранном APK
есть только служебное `com.legacy.fingame.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` уровня
`signature`: его добавляет AndroidX Core, оно доступно только самому приложению и пользователю не
показывается. Проверка:

```bash
$ANDROID_HOME/build-tools/37.0.0/aapt2 dump permissions app/build/outputs/apk/release/app-release-unsigned.apk
```

Разрешения `INTERNET` нет — приложение технически не может передавать данные по сети. Тег
`<attribution>` в манифесте нужен для воспроизведения звука и разрешений не добавляет.

## 4. Какие данные хранятся

| Данные | Где | Передаются ли |
|---|---|---|
| Имя питомца (вводит ребёнок), выбранное животное | `SharedPreferences` `player` | нет |
| Игровой прогресс: баланс, вклад, бюджет, покупки, цели, шкалы, журнал, квесты, закрытые подсказки | `SharedPreferences` `player` | нет |
| Тексты взрослого: причины изменения монет, свои предметы и квесты; журнал использованных наград | `SharedPreferences` `player` | нет |
| Громкость звуков и музыки, тема | `SharedPreferences` `fin_game_settings` | нет |

Персональные данные ребёнка и родителя (ФИО, возраст, контакты) не запрашиваются, учётных записей
нет. Аналитики, рекламы, покупок, идентификаторов устройства и сетевых SDK нет. В logcat пишутся
только технические сведения о повреждённых данных и отсутствующих файлах.

Резервное копирование: в манифесте `android:allowBackup="true"` с шаблонными правилами
(`res/xml/backup_rules.xml`, `data_extraction_rules.xml` — без исключений). На устройстве с
включённым резервным копированием Google система может сохранить файлы приложения в копию аккаунта
пользователя и восстановить их при переустановке. Само приложение ничего не отправляет.

## 5. Удаление профиля

1. **В игре:** «Настройки» → «Сбросить прогресс» → подтверждение «Вы уверены, что хотите сбросить
   весь прогресс? Это действие нельзя отменить.» Удаляются питомец, деньги, бюджет, вклад, предметы,
   цели, журнал, квесты; подсказки по экранам покажутся снова; игра возвращается к выбору питомца.
   Остаются настройки звука и темы, а также свои предметы и квесты взрослого
   (`GameViewModel.resetProgress`).
2. **Очистка данных приложения:** «Настройки Android» → «Приложения» → Fin Game → «Хранилище» →
   «Очистить данные» — удаляет всё, включая настройки и данные взрослого.
3. **Удаление приложения** удаляет все его данные. Если было включено резервное копирование Google,
   копию можно удалить в настройках аккаунта Google.
