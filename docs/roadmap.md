# Известные ограничения и план развития

Связанные разделы: [матрица требований](requirements.md), [UX и доступность](ux-accessibility.md),
[рост питомца](pet-growth.md).

## 1. Ограничения прототипа

| Ограничение | Последствие |
|---|---|
| Нет сервера и синхронизации | Прогресс живёт на одном устройстве; взрослый видит отчёты только на устройстве ребёнка |
| Один профиль на установку | Двое детей не могут играть на одном устройстве раздельно |
| Одна локаль (русский), строки в коде | Для перевода строки нужно вынести в ресурсы |
| Баланс не откалиброван | Цены, доход, ставки вклада, скорость убывания шкал, пороги ухода и награды квестов подобраны вручную и не проверены на детях |
| Рост от ухода считается по дням питомца | Рост и штрафы начисляются в конце каждого дня питомца, а не непрерывно |
| День оценивается по лучшему индексу ухода | Полная забота перед самым концом дня засчитывает его как хороший; выигрыш — не больше одного дня |
| Эффекты вариантов квестов не засчитываются как забота за день | Квест может поднять шкалы, но лучший индекс ухода за день поднимают только предметы |
| Рост зависит только от ухода | Соблюдение плана бюджета и регулярность накоплений на рост питомца не влияют |
| Одна комната | Переключение подлокаций в модели осталось, но фон и кнопки есть только для одной |
| У питомца по одному кадру на этап | Покадровой анимации нет; переключателя анимаций в настройках нет |
| У мишки (`teddy`) нет спрайта | В магазине и инвентаре показывается заглушка |
| Своя одежда и декор взрослого без рисунка на сцене | На питомце и в комнате вместо них рисуется заглушка |
| Сердечки поглаживания рассчитаны на голову кота | Для животного другой формы высоту головы нужно задавать отдельно ([animals.md](animals.md)) |
| Встроенных квестов 4 | До 6 по ТЗ добирается своими квестами взрослого |
| Картинки квестов не нарисованы | На карточках показывается общая иконка |
| Проверка взрослым — на каждом шаге квеста | Режима «проверить только в конце» нет |
| Тема «Честность» осваивается только через случайный квест | Статус темы зависит от того, выпал ли «Потерянный кошелёк» |
| Замок взрослого — примеры на умножение | Защищает от маленьких детей, но не от школьника, знающего таблицу умножения |
| Часть элементов меньше рекомендаций ТЗ | Кнопки закрытия и «−/+» — 40 dp вместо 48; часть вспомогательного текста мельче 16 sp |
| Релизная подпись ручная, R8 отключён | APK больше, чем мог бы быть; сборка и подпись релиза не настроены в CI |
| Резервное копирование Android включено по умолчанию | См. [ux-accessibility.md](ux-accessibility.md), раздел 4 |
| Проверка на физических устройствах не задокументирована | См. [testing.md](testing.md), раздел 4 |

## 2. План развития

1. Откалибровать экономику и правила ухода на тестовой группе детей и родителей.
2. Учитывать в росте питомца соблюдение плана и регулярность накоплений, а не только уход.
3. Добавить квесты до 6+ встроенных по темам «Вклад» и «Цели», нарисовать картинки квестов.
4. Нарисовать спрайт мишки, анимации питомца и добавить переключатель анимаций; увеличить мелкие
   кнопки до 48 dp.
5. Вернуть несколько комнат (фоны и кнопки переключения).
6. Профили нескольких детей на одном устройстве.
7. Вынести строки в ресурсы, добавить английскую локаль.
8. Новые темы: кредит и долг, сравнение цен, регулярные платежи, инфляция.
9. Подпись релиза из переменных окружения, R8, CI со сборкой и тестами.
10. Опциональная синхронизация взрослого и ребёнка (потребует сервера, согласия законного
    представителя и политики конфиденциальности).
